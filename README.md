Aggregate Functions Explanation

Aggregate functions perform calculations on multiple rows and return a single result.

- COUNT() – Counts the total number of students.
- AVG() – Calculates the average CGPA of all students.
- MAX() – Finds the highest CGPA.
- MIN() – Finds the lowest CGPA.
- SUM() – Calculates the total of all students' CGPAs.

The GROUP BY clause groups students according to their department, allowing us to find the number of students and average CGPA for each department.
